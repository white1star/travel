# 旅行计划 · 核心体验版

根据产品 PRD 实现的一站式旅行规划网站。支持空白创建、AI 多日规划、真实地图地点、行程编辑、预算和交通住宿管理：

生产地址：<https://travel-plan-cn.netlify.app>

- 创建页首次打开保持空白，不预填演示城市、日期、人数或预算；旧版本内置示例草稿会自动清除
- 创建向导填写基本信息，可跳过可选偏好直接确认
- 填写出发地、目的地、日期、天数、人数与预算
- 选择旅行节奏、兴趣和必去地点；这些偏好会真实改变地点排序和每日密度
- 确认步骤提供“AI 生成行程”和“普通生成”：AI 使用 DeepSeek 从高德真实候选地点中生成完整多日计划，普通生成作为离线备用
- 先生成可审阅的按天行程与分类预算，确认后才保存到“我的行程”
- 已知地点生成坐标与费用估算；未收录地点保留为“待定位”，不会伪造数据
- 预算不足时优先减少普通付费景点，用户指定的必去地点仍会保留
- 生成按天拆分的时间轴、路线地图与预算概览
- 桌面端双栏展示，手机端先展示日程
- 多份行程保存在当前浏览器中，支持搜索、重命名、独立复制
- 创建草稿自动保留填写内容和步骤，确认页可直接返回修改；清空需确认
- 删除先移入回收站，支持恢复；永久删除需再次确认，回收站不自动清理
- 行程详情显示保存状态，失败保留修改；未保存时刷新、关闭或点击站内链接会提醒
- 行程修改停止 600ms 后自动保存，支持失败重试和最多 20 步撤销
- 桌面端可拖拽调整当天顺序，手机端和键盘可用上移/下移；支持同城跨日移动、复制当天和清空普通安排
- 支持精确修改开始时间与停留时长，并提示时间重叠、结束过晚、安排过密和待定位地点
- 手动管理交通、住宿、确认状态和预订费用，并提示住宿缺口、日期范围与日程冲突
- 在行程预算页按人均调整交通、住宿、餐饮、门票、本地交通和其他分类额度
- 预订费用可选择“每人”或“整单”口径；有效交通住宿费用会替代对应生成估算，避免重复计算
- 同时查看人均与整团计划支出、未分配额度、分类超支和费用待补充提醒
- 行程详情可按“当前这一天”请求 AI 推荐：DeepSeek 结合当天城市、节奏、预算、已有安排和临时要求排时间，地点必须来自高德真实候选；用户预览勾选后才一次性加入，并可整批撤销

本地行程库使用 `travel:library:v2` 单记录保存行程、回收站和当前选择，避免多个键分步写入造成半完成操作。首次写入兼容旧版本数据，新记录成功保存后清理旧版副本。数据仅在当前浏览器，不是账号云同步；清除浏览器数据仍会丢失本地行程。浏览器后退/前进等历史导航不属于当前站内链接提醒覆盖范围。

## 本地运行

前端：

```powershell
pnpm install
pnpm dev
```

后端（另开一个终端）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r apps\api\requirements.txt
Set-Location apps\api
& '..\..\.venv\Scripts\python.exe' -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000 --env-file .env.local
```

启动前按 `apps/api/.env.example` 创建被忽略的 `apps/api/.env.local`，配置高德 Web 服务 Key、Web 端 JS Key、安全密钥，以及服务端 DeepSeek 配置：

```text
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_TIMEOUT_SECONDS=25
```

DeepSeek Key 只能放在后端本地环境或生产秘密管理服务，不能使用 `NEXT_PUBLIC_` 前缀。前端按 `apps/web/.env.example` 指向本地后端。打开 <http://localhost:3000>（当前本机调试也可使用 3001 端口）。

## 当前边界

创建页的“AI 生成行程”和行程详情的“AI 推荐”都会实时调用 DeepSeek，并只允许模型从本次高德候选中选择地点；名称、地址和坐标由后端可信数据回填，模型不能虚构地点。AI 或地图服务不可用时会明确提示，用户可以改用普通生成，手动添加、日程编辑、预算和交通住宿仍可使用。所有结果仍是出发前建议，不代表实时开放、票价或可订状态。配置及联调边界见 [地图接入说明](docs/map-integration.md)。交通与住宿信息由用户手动录入，平台不向供应商核验，也不提供实时价格、航班状态、出票或支付。预算功能仅用于出发前规划，不包含实际消费记账、多币种、AA 分账或报销。票务预订、账号与云同步尚未接入，本地数据不会同步到其他设备。

## Netlify 发布

项目通过 Next.js 静态导出发布，构建目录为 `apps/web/out`。地图和 AI 推荐都需要独立、常驻的 HTTPS FastAPI 后端；仅上传静态目录不会获得这些能力。正式发布前必须轮换所有曾在截图或聊天中出现过的高德与 DeepSeek 密钥，并完成域名、服务端 IP、鉴权与额度限制。本轮不执行部署。
